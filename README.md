# Kunjal Mahajan — Portfolio

A simple, single-page personal portfolio (plain HTML + CSS, no build step).

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`.
3. The site will be live at `https://kunjalmahajan02.github.io/my-portfolio/`.
